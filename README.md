# Panel Ready

Panel Ready is an interview-practice web app. It uses a candidate's resume and
a saved role to prepare a mock interview with three rounds:

1. **Technical lead** — role fundamentals, technical skills, testing, and
   design decisions.
2. **HR interviewer** — communication, ownership, teamwork, and motivation.
3. **Hiring manager** — resume projects, problem solving, and practical
   judgment.

The app creates ten questions tailored to the resume and role: four in the
technical round, three in the HR round, and three in the hiring manager
round. Candidates can type or speak answers. Each interviewer reviews answers,
may ask one follow-up question, and generates a final summary with topics to
work on. The app can also search public web results for optional company and
role context.

## How it works

- `app.py` provides the FastAPI app, interview flow, and API.
- `interview_tracker.html` contains the browser interface.
- SQLite stores account, profile, role, interview, and practice-progress data.
- Groq generates interview questions and coaching. DuckDuckGo supplies
  optional public search results.
- `render.yaml` configures deployment on Render.

The panelist for a round provides feedback on that round's answers. This is
practice feedback generated by a language model, not a real hiring decision.


## Data and limitations

The app stores profile and interview data in SQLite. Resume/profile details,
job information, and answers are sent to Groq for coaching; search queries
are sent to DuckDuckGo. Avoid entering confidential information.

This is a project demo, not a production service for sensitive data. It does
not include email verification, password recovery, or self-service account
deletion.
